# 🐧 Learn Linux — A Practical Guide

A structured, hands-on repository for learning Linux from scratch to advanced level.

## 📚 Curriculum Overview

| Module | Topic                   | Level	  |
|--------|-------------------------|--------------|
| 01 	 | Basics & Navigation     | Beginner     |
| 02	 | File System 		   | Beginner     |
| 03	 | Permissions & Ownership | Beginner     |
| 04 	 | Processes & Jobs        | Intermediate |
| 05 	 | Networking              | Intermediate |
| 06 	 | Text Processing         | Intermediate |
| 07 	 | Shell Scripting         | Intermediate |
| 08 	 | Package Management      | Intermediate |
| 09	 | System Administration   | Advanced     |
| 10	 | Advanced Topics         | Advanced     |

## 🚀 Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/learn-linux.git
   cd learn-linux
   ```

2. Start with module 01 and work your way through each topic.
3. Complete the exercises at the end of each module.
4. Use the cheatsheets as quick references.

## 💡 How to Use This Repository

- Each module has a `README.md` with theory and examples.
- Practice files and scripts are included in each module.
- The `exercises/` folder has challenges with solutions.
- The `cheatsheets/` folder has quick-reference cards.

## 🧪 Prerequisites

- A Linux system (Ubuntu, Debian, Fedora, etc.) or
- WSL (Windows Subsystem for Linux) on Windows, or
- A virtual machine with any Linux distribution
